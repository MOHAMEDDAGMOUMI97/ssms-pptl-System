This directory contains figures for the SSMS report.

Place your images in this folder and reference them from .tex files as:
  \includegraphics[width=\linewidth]{figures/your_image_name.jpg}

Required figures (to be added by student):
  - hardware_photo.jpg: Photo of assembled PCB/prototype
  - application_picking_screen.png: Screenshot of the desktop app
  - ltspice_waveform.png: LTspice simulation output
  - proteus_screenshot.png: Proteus simulation screenshot
  - schematic_ssms.pdf: KiCad schematic export (full page)
