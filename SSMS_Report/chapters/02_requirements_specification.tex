\section{Use Case Description}
\label{sec:usecase}

The SSMS involves three primary actors:

\begin{itemize}
  \item \textbf{Operator:} The warehouse worker who interacts with the system to perform picking and stocking operations.
  \item \textbf{Administrator:} The supervisor or IT staff who configures the system, loads batch data, and reviews history.
  \item \textbf{System:} The SSMS hardware and software that processes commands and controls the LEDs.
\end{itemize}

\section{Communication Protocol Requirements}
\label{sec:mqtt-req}

\subsection{MQTT Configuration}
\label{sec:mqtt-config}

\begin{itemize}
  \item \textbf{Broker:} Mosquitto MQTT broker running on the local LAN.
  \item \textbf{QoS:} Level 1 (at least once delivery) for all commands and status messages.
  \item \textbf{Topics:}
  \begin{itemize}
    \item \texttt{ssms/command} --- Desktop application publishes LED commands here.
    \item \texttt{ssms/status} --- ESP32 publishes status updates here.
  \end{itemize}
\end{itemize}
